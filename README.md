
🚀 Eat & Repeat – Food Delivery Web App
📌 Overview

Eat & Repeat is a modern food delivery web application that allows users to browse food items, add them to cart, and complete checkout with a smooth and interactive experience.

The project focuses on combining frontend development with product thinking, including AI-based recommendations and smart UX improvements.

🎯 Features
🛒 Core Features
Browse food items by category
Add to cart with quantity control
Remove items from cart
Real-time total price calculation
Checkout with payment options (Online / Cash on Delivery)
🤖 AI-Based Recommendation System
Suggests food items based on user cart behavior
Uses category-based logic to recommend similar items
Improves user engagement and discovery

💡 This simulates how AI-driven systems personalize user experience

⚡ Smart UX Improvements
Free delivery nudge (encourages higher cart value)
Clean and responsive UI
Simple and intuitive navigation
🧠 Product Thinking

This project was enhanced with a focus on:

Improving user decision-making
Increasing engagement through recommendations
Reducing friction in checkout flow
🛠️ Tech Stack
React.js
JavaScript (ES6+)
CSS
Material UI Icons
Vite

⚙️ How It Works
User browses food items
Adds items to cart
System calculates total
AI suggests similar items
User proceeds to checkout
Payment is simulated
